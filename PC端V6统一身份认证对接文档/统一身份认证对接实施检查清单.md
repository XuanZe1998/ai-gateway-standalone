## 四 本地登录逻辑

- [ ] `doLogin` 不再直接返回成功
- [ ] 检查 CAS `account` 非空
- [ ] 已确定 `localAccount` 与 `account` 的映射优先级

- [ ] 登录失败有明确页面或错误处理

## 五 安全加固

- [ ] Java 已移除 `trustEveryone()` 式全局信任
- [ ] .NET 已移除始终返回 `true` 的证书验证回调
- [ ] PHP 已移除 `setNoCasServerValidation()`
- [ ] CAS 证书链和主机名得到正常验证
- [ ] `targetUrl` 仅允许站内地址或白名单地址
- [ ] 防止 Session 固定
- [ ] Session Cookie 启用 `Secure`、`HttpOnly` 和适当的 `SameSite`
- [ ] 业务功能仍执行本地授权校验
