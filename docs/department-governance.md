## 使用说明

### 跨部门按身份批量免费并限量

入口：管理员「部门与用量管理 → 部门与用量 → 按用户与身份管理」。这里直接列出跨部门成员，不必逐个部门重复操作。

1. 选择身份类型（以实际 CAS 身份编码和名称为准），可同时组合部门名称或编码、角色、个人或企业计费账户、校园身份启停状态、当前免费资格和姓名账号，点击「查询」。身份未知会单独显示，不能猜测为教师或学生。
2. 勾选成员，或选择「全部符合筛选的当前成员（跨页）」。点击「批量免费并限量」。
3. 填写每人每月使用金额上限，例如 `100` 元，或 Token 上限，例如 `1000000`；可仅设置金额、仅设置 Token，或两者同时设置，至少设置一项。填写原因，预览影响名单后确认。金额设为 0 会停止新的相关调用；个人留空的维度继承部门默认，无默认才不限制，预览逐人列出生效的金额和 Token 上限。部门总预算仍然适用。
4. 免费期间不实际扣款。使用金额按正常计费规则在免费减免前计算，包含适用折扣与调价，是预算计量金额，不是上游成本。任一预算耗尽后停止新的相关调用，不自动转为付费。已记录的当月使用金额、Token 和进行中预占继续累计，调整上限不会清零；按北京时间自然月重新计算。Token 上限不限制图片张数或音视频时长，金额预算则计量现有定价链路能够确认的这些资源价值；它不能替代次数、并发或频率限制。

日期、模型、服务及账单免费方式是统计筛选；管理对象以当前身份、当前免费资格等目录筛选为准。预览会固定本次跨部门名单，新加入用户不自动获得本次授权；提交前身份、部门或规则变化会要求重新预览。操作记录同时在跨部门入口与受影响部门中展示。个人例外按用户实际所属部门保存，转部门后终止；可选中成员批量「恢复部门默认」。

「批量分配额度」里的余额追加是充值，月度免费 Token 总额是原有免费额度指标，二者均不能单独限制管理员免费资格；应使用上述使用金额／Token 预算。免费账单金额仍为零，页面单独显示使用金额、已用及预占和实际扣费。本次跨部门操作针对当前成员，不创建面向未来用户的身份自动授权规则。

历史免费账单没有保留免费减免前的计价值，V27 不按当前价格追算，也不伪造为已知零元；显示计价未知，不参与可确认的使用金额合计。正在进行或待核对的调用金额不明时，新金额预算调用会暂停，需先结算或核对。已确认的旧正常付费账单可以按原账单金额补记预算价值，不影响实际扣费。

- 默认北京时间本月，支持今日、近 7 天、自定义日期，以及部门、用户、模型、服务和免费使用方式筛选。部门排行可以按费用、Token、账单数和名称排序；进入部门查看成员，再打开个人详情查看每日趋势、模型、Key 和分页账单。
- 免费用户的实际用量照常累计，账单费用为零；月度免费 Token 已用量是另一指标。总 Token 使用互斥的归一化维度，不能把输入总量再与缓存相加。图片张数、视频秒数等计量在账单展开项展示。
- 账单费用与已确认扣费分别显示。旧账单没有扣费回执，显示「历史未确认」，不根据金额猜测扣款成功。历史部门没有可靠快照的记录统一进入「历史归属未知」。
- 当前人数、免费人数和使用规则来自当前身份；用量、免费使用筛选和费用来自所选期间的账单快照。转出用户仍可在原部门看到历史消耗，不能继续参与原部门批量分配。
- 报表导出使用与页面相同的过滤和聚合，包含全部匹配记录，不限当前页；上限 10 万行，超过后需缩小范围。CSV 对公式前缀做保护。

## 额度、规则与预览

部门默认规则包含免费资格、额度来源、部门月度 Token 预算、每人金额和 Token 上限及预警阈值。优先级是个人例外、部门默认、平台默认。默认保留个人例外，覆盖例外需要明确勾选；恢复部门默认会移除当前部门的个人例外。校园身份同步转部门时，旧例外存档后终止，返回原部门也不会自动恢复旧授权。

一次性分配与未来默认规则分开：

1. **批量分配**：每个实际到账账户追加金额；同一企业账户只追加一次。月度免费 Token 总额逐人设置，保留当月已用量和跨月重置规则。新加入成员不会补发这笔一次性充值。
2. **部门共享池**：独立金额账户，余额跨月保留；部门月度 Token 预算按请求开始的北京时间自然月核算。只对选择部门额度来源的成员承担金额，不会自动转扣个人／企业账户。

批量操作必须填写原因并先预览。预览冻结成员及实际到账账户，有效期 30 分钟。提交时锁定部门、用户和账户并重新校验；身份、到账账户、额度策略或部门规则改变时要求重新预览。正常调用导致的余额和已用量变化不会使追加操作失效，提交时仍保留最新已用量。

同批次重复提交返回原结果。每批是数据库事务，任一成员失败则整批回滚，不产生部分到账；失败批次可在条件仍匹配时重试，目标改变则重新预览。操作记录包含原因、操作人、批次及提交前后的变更。

## 调用与结算

- 请求开始时保存部门、使用方式、额度来源、限额及规则来源快照；普通、流式及视频异步任务共享此口径，不按结算时的新部门或新免费资格追溯重算。
- 使用数据库事务和部门锁完成预占，跨节点共用同一份预算；有可靠请求上限的文本、图片和按秒视频按保守金额／Token 估算预占。
- 对缺少输出上限、远程多模态素材、语音、视频 Token 计费等无法可靠预估的请求，保守预占其适用的全部剩余预算，实际结算后释放差额。这些请求可能暂时占满可用预算，其他请求需等待结算；不会偷偷改用个人余额。
- 免费资格免实际金额扣费及个人月度免费 Token 扣减，仍受适用的使用金额及 Token 上限限制；使用金额预占独立于共享余额预占，免费调用不锁定或扣减部门资金。
- 有明确请求用量上界时保守估算金额，纳入正向固定调价和折扣倍率；无法可靠预估时预占适用的全部剩余预算。预占是估算，不能中途撤回已经生成的资源；单次无上界调用或上游超出承诺用量可能产生超额消耗，仍据实记账，之后的调用停止。重复结算不重复累计，取消且已确认未发生用量时释放预占。
- 启用免费使用金额预算后，旧版本不识别这一控制口径。回滚前必须暂停相关调用并处理在途记录，或转换为旧版本能够执行的限制；不得直接回退后继续提供无限免费调用。
- 结算按请求编号幂等落账，共享池扣款和回执在同一事务提交。个人／企业账户的扣款和回执也在同一事务提交，不把账单生成当成扣费成功。
- 实际账单超过池中可用金额时，不扣成负数，保留待结算和预占。管理员追加金额后可在「预占与待核对记录」重试共享扣费；重复重试不会重复扣费。
- 上游未返回可确认用量或计费异常时保留预占，显示原因，禁止将未知消耗默认为免费。此类记录须核对上游真实用量后处理，不能直接按估算金额扣费。
- 失败、取消的已确认视频终态释放预占。流式客户端断连沿用现有上游继续消费和结算行为，不能仅因前端断连免除已生成资源的费用。进程故障遗留的预占不自动按超时释放，避免长任务仍运行时重复放出预算；管理端可查看保留记录供核对。
- 月度 Token 预警按自然月；金额预警按共享池累计追加总额与当前余额计算。同部门、月份、指标和阈值只记录一次，默认 80%、90%、100%；管理操作及结算后刷新，并每 5 分钟补查。Token 提醒包含进行中预占，金额提醒以已扣款为准。本月已触发提醒保留为记录，不代表充值后仍不可调用。

## 数据与接口

新增 Flyway `V26__department_governance.sql`，在 V25 后执行，新增当前成员视图、部门规则、共享账户、请求预占、批次、提醒和例外历史；账单与视频任务增加归属／规则快照及结算字段。不会自动迁移个人或企业资金，不会自动给部门启用共享支付。

`/api/admin/departments` 下提供：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /report` | 部门排行／成员报表；`members=true` 切换成员，`page` 从 0 开始 |
| `GET /detail?department=…` | 部门规则、共享账户、月度用量、提醒、操作与待核对记录 |
| `GET /users/{owner}` | 个人详情；`billPage`、`billSize` 控制账单分页 |
| `GET /export` | CSV，沿用报表筛选和 `members` |
| `GET /alerts` | 当前自然月提醒，可按部门筛选 |
| `POST /batches/preview` | 预览 `ALLOCATE`、`POLICY`、`RESET_POLICY`、`DEPARTMENT_POLICY`、`POOL_TOPUP` |
| `POST /batches/{id}/commit` | 幂等提交或重试同一批次 |
| `POST /reservations/{id}/retry` | 已知用量的共享池待结算重试，须填写原因 |

报表公共筛选为 `start`、`end`（ISO 日期，含首尾）、`department`、`departmentSearch`、`search`（姓名／账号）、`model`、`service`、`freeUsage`、`sort`。单次日期跨度最多两年。
