# AI Gateway 项目周报

**汇报周期：** 2026-09-14 至 2026-09-18  
**项目：** 南通算力平台 AI Gateway  
**本周主题：** 单机可用性收口、监控模块修复、校级统一认证与全校集群化准备

## 一、本周工作概述

本周工作从“项目能启动、模型能调用”继续向“可管理、可审计、可安全开放、可集群部署”推进，完成了以下五条主线：

1. 修复独立版项目启停、构建和容器化部署问题；
2. 完善上游模型自动发现与批量导入，降低模型配置成本；
3. 修复 Token 用量统计无数据和异常管理模块报错；
4. 实现教师 OIDC 统一认证、专属访问入口和 mTLS 受管设备绑定；
5. 建立面向全校师生的分布式部署基线，包括共享配置、分布式限流、师生配额、Kubernetes 和生产上线手册。

## 二、本周完成事项

### 1. 独立版启动与部署稳定性

- 修复 `start.ps1` 启动报错，增加 Docker/Docker Compose/Docker Engine 前置检查。
- 增加 Java 17 `JAVA_HOME` 自动识别、JAR 增量构建判断、容器健康等待和超时日志输出。
- 完善 `Dockerfile.standalone`、Docker Compose、停止脚本及外部配置挂载。
- 确认 PostgreSQL 数据、模型实例配置和管理状态在重启后可继续加载。
- 补充独立版启动、上游模型配置和集群验证文档。

### 2. 模型自动发现与导入

- 新增上游 `/v1/models` 模型发现服务。
- 支持从完整请求地址推导模型列表地址，并转发必要认证头。
- 兼容多种上游返回结构，对无模型、非 HTTP 地址和上游 HTTP 错误进行明确提示。
- 完成管理后台“发现模型—选择模型—批量导入实例”交互。
- 本地烟测时 `/v1/models` 恢复为 HTTP 200，返回 87 个可用模型。

### 3. Token 用量统计修复

- 定位“页面无内容”的根因：统计页查询的旧用量表与实际计费记录数据源不一致。
- 统一改为从计费记录汇总 Token 用量，确保统计与计费口径一致。
- 补齐按模型、服务类型、供应商、用户、API Key 的聚合统计。
- 补齐日/周/月/小时趋势数据和最近调用记录映射。
- 增加统计口径和前端数据契约测试。

### 4. 异常管理模块修复

- 对异常列表、详情、统计、最近异常和历史数据清理进行全功能回归。
- 重构异常查询的组合筛选和分页，增加页码、页大小和排序字段白名单校验。
- 修复最近异常数量越界、无效排序参数及统计计数不一致问题。
- 修复前端异常列表、详情和统计页的字段对应与展示问题。
- 补强异常持久化容错、审计字段长度契约及异步链路处理后队列清理。

### 5. 教师统一认证与防凭据外借

- 接入 Spring Security OIDC 授权码登录，支持按 `system_user_id` 或工号关联算力平台实名用户。
- 新增教师身份、受信设备和专属入口三类数据模型及数据库表。
- 为每位教师生成专属 `/u/{endpointId}/v1` 入口和短期 `ntit_at_` 访问令牌。
- 使用 mTLS 客户端证书指纹将“教师身份 + 专属 URL + 短令牌 + 受管设备”绑定。
- 新增设备绑定、访问配置获取、设备列表和设备撤销接口。
- 实现无设备证书、换设备证书、使用他人专属地址、设备被撤销等场景的即时拒绝。
- 提供 mTLS 开发联调编排和完整部署说明，功能默认关闭，避免未配置学校 IdP/CA 时误启用。

### 6. 全校师生分布式部署基线

- 建立 `cluster` 运行模式，将运行时配置集中存储于 PostgreSQL，多副本轮询配置修订号并自动刷新本地缓存。
- 增加 Redis Lua 原子令牌桶，使服务、实例、全局和客户端 IP 限流在多副本间一致。
- 将 API 副本和单 Worker 职责分离，避免月度配额重置等定时任务重复执行。
- 增加配置乐观锁和版本唯一约束，降低多管理员并发修改的覆盖风险。
- 完成学生/教职工/教师月度免费 Token 配额和管理员单人/批量预置接口。
- 增加 OIDC 共享 Redis Session，使登录状态不依赖入口会话粘滞。
- 提供三副本 Compose 验证环境以及 Kubernetes 生产基线，包括 HPA、PDB、反亲和、优雅停机、健康探针和滚动发布。
- 提供 Flyway V8 基线 + V9 迁移、ExternalSecret、ServiceMonitor、PrometheusRule、NetworkPolicy 模板。
- 新增 k6 压测脚本，默认验收门槛为错误率小于 1%、P95 小于 2 秒、P99 小于 5 秒。

## 三、本周关键问题闭环

| 问题 | 根因 | 处理结果 |
|---|---|---|
| `start.ps1` 启动失败 | Docker/Java/构建和健康检查流程不完整 | 增加前置检查、自动构建、健康等待和失败日志 |
| Token 统计页无数据 | 统计和计费使用不同数据源 | 统一到计费记录，完善多维度与时间趋势汇总 |
| 异常管理页报错 | 查询参数、排序字段、统计口径及前后端契约不统一 | 重构查询与分页，修复前端展示并完成全功能回归 |
| 教师 Key/URL 可被转借 | 传统静态凭据不能识别调用设备 | 实现 OIDC + 短令牌 + 专属 URL + mTLS 设备证书四重绑定 |
| 教师 JWT 全部被判无效 | JJWT 新版将 `aud` 解析为集合 | 改为标准 audience 集合校验并增加回归测试 |
| 专属 URL 无法传递给认证器 | 路径重写过滤器晚于 Security 执行 | 明确将专属路径过滤器放到 Spring Security 之前 |
| 教师功能关闭时接口返回 500 | 安全规则仍强制认证 | 改为正确返回 404，不影响现有部署 |
| `/v1/models` 被误拦截 | 路径重写前后的匿名规则不完整 | 同时放行 `/v1/models` 与 `/api/v1/models`，烟测恢复 200 |
| 多副本配置和限流不一致 | 单机文件存储与本地令牌桶无法跨节点共享 | 实现 PostgreSQL 修订号同步与 Redis Lua 原子限流 |

## 七、可用于周会的口头汇报

> 本周 AI Gateway 项目主要完成了三个阶段性目标。第一，对现有单机版进行了稳定性收口，修复了一键启动、Token 用量无数据和异常管理报错，同时增加了上游模型自动发现和批量导入。第二，完成了教师统一认证和受管设备绑定的后端闭环，通过 OIDC、专属 URL、短令牌和 mTLS 设备证书绑定，解决教师将 Key 和 URL 外借后在其他设备使用的问题。第三，建立了面向全校师生的集群化基线，包括共享配置、Redis 分布式限流、师生月度配额、Kubernetes 部署、监控告警和压测脚本。本周最终回归共 1246 个用例，全部通过。下一步的主要依赖是学校提供真实 OIDC、CA、数据库和 Redis 参数，然后进入预生产联调、故障演练和容量压测。
